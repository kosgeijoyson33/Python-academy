Lesson 1: Introduction to Python

Welcome to your first Python programming lesson. In this lesson, you will learn how to write your first Python program.

What is Python?

Python is a programming language used to create websites, applications, automation tools, artificial intelligence and many other systems.

Your First Python Program

Python uses the print() function to display information on the screen. 

print("Hello, World!")

This program displays the message: 

Hello, World!

Understanding the Code

print() is a Python function that displays information.

The text inside quotation marks is the message that Python displays.

Practice Exercise

Write a Python program that displays your name.

Example: 

print("My name is Metto")

Lesson Summary

You have learned:

  • What Python is.
  • What the print() function does.
  • How to display text.
  • How to write a simple Python program.
