Lesson 1: Introduction to Python

Welcome to Python Academy! In this lesson, you will learn the basics of Python programming, understand how Python works, and write your first simple programs.

1. What is Python?

Python is a high-level, general-purpose programming language used to develop applications, websites, automation tools, artificial intelligence systems, and data analysis programs.

Python is popular because its syntax is simple and easy to understand. Beginners can use it to learn programming concepts without dealing with complicated code.

Uses of Python

  • Web development
  • Artificial intelligence
  • Machine learning
  • Data analysis
  • Automation
  • Desktop applications
  • Cybersecurity tools
  • Scientific computing

2. Your First Python Program

The first program most Python learners write displays the message: Hello, World!

Python uses the print() function to display information on the screen. 

print("Hello, World!")

Understanding the code

  • print() displays information.
  • The text inside quotation marks is displayed on the screen.
  • Python executes the instruction when the program runs.

Expected output

Hello, World!

Remember: Python is case-sensitive. The word print must be written in lowercase letters.

3. Comments in Python

Comments are notes written inside a program. They help programmers understand what the code does.

Python uses the hash symbol # to create a comment. 

# This is a comment

print("Welcome to Python")

Python ignores comments when executing the program.

4. Variables in Python

A variable is a name used to store information in a program.

Variables allow programmers to save values and use them later.

Example

name = "Joyson"

age = 22

print(name)

print(age)

Expected output

Joyson
22

In this example:

  • name stores text.
  • age stores a number.
  • The print function displays the values.

Rules for naming variables

  • Variable names cannot start with a number.
  • Variable names cannot contain spaces.
  • Variable names can contain letters and numbers.
  • Underscores can be used in variable names.
  • Python keywords cannot be used as variable names.

Example of valid variables

student_name = "Joyson"

student_age = 22

course = "Python"

5. Python Data Types

Data types describe the kind of information stored in a variable.

Python has several built-in data types.

String

A string stores text. 

name = "Joyson"

print(name)

Integer

An integer stores a whole number. 

age = 22

print(age)

Float

A float stores a decimal number. 

price = 150.50

print(price)

Boolean

A Boolean stores either True or False. 

is_student = True

print(is_student)

Summary of data types

Data Type Description Example
String Text "Python"
Integer Whole number 25
Float Decimal number 25.5
Boolean True or False True

7. Input and Output

Python allows users to enter information using the input() function.

Example

name = input("Enter your name: ")

print("Welcome", name)

When the program runs, it asks the user to enter their name.

Example output

Enter your name: Joyson

Welcome Joyson

Using input with numbers

The input() function returns text. To perform calculations, convert the input into a number. 

age = int(input("Enter your age: "))

print(age)

The int() function converts the input into an integer.

8. Simple Python Program

Let's combine variables, input, and mathematical operations.

Program: Simple Calculator

num1 = int(input("Enter first number: "))

num2 = int(input("Enter second number: "))

sum_result = num1 + num2

print("The sum is:", sum_result)

Example output

Enter first number: 10

Enter second number: 20

The sum is: 30

Learning tip: Try changing the numbers and observe how the output changes.
